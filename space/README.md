# CineCue

Explainable movie recommendations (EASE + matrix factorization) built on MovieLens.
Source, notebooks and evaluation: https://github.com/zaeem886/cinecue.

This Space is private to the team. It loads its fitted models from a private GitHub
repository, because they contain MovieLens ratings, which GroupLens does not allow to be
redistributed. Posters are loaded from Wikipedia.
